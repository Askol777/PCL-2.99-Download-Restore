# PCL 正式版 2.99.0.0（413.50） 下载功能恢复补丁｜使用教程

适用对象：**Plain Craft Launcher 2.99.0.0 正式版 2.99.0.0（413.50）**。

此工具通过本地修改**用户自己提供的原始 EXE**，恢复 Minecraft 原版下载和整合包下载/安装。它不包含、不会自动下载 PCL EXE。此次打包合并了此前的全部修正，无需逐阶段安装。

## 1. 使用前须知

- **仅支持本教程对应版本的精确二进制构建**；即使版本号相同，只要 SHA-256 不匹配，就会拒绝修改。这是保护机制，不是故障。
- 只处理 `Plain Craft Launcher 2.exe`，不需要更改游戏文件夹中的资源、Mod、存档、Java 或登录配置。
- 首次使用建议先将原版 PCL **整个程序目录复制一份作为测试副本**，然后对测试副本执行补丁。先退出所有 PCL 进程。
- 补丁直接写入 EXE，**无需每次运行重新打补丁**。程序更新或替换 EXE 后，需重新核对哈希，不能将这个旧补丁用于新版本。
- 使用 Windows PowerShell 5.1（Windows 自带）。下面的命令不会固定任何磁盘、用户或文件夹路径。
- 补丁工具仅修补用户已拥有的软件文件。传播工具前请核对软件作者许可及所在地法律；不要将本补丁包宣传为官方修改版，也不要擅自分发 PCL EXE。

## 2. 解压并打开终端

1. 解压整个 ZIP，确保 `Patch.ps1`、`manifest.json` 和 `payload.bin` 在同一文件夹。
2. 打开这个**解压后的文件夹**，在资源管理器空白处右键，选择“在终端中打开”（或在资源管理器地址栏输入 `powershell` 回车）。
3. **先执行预览**。脚本会打开文件选择窗口，手动选择要修补的 `Plain Craft Launcher 2.exe`。无需复制或输入路径。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File ".\Patch.ps1" -Mode Preview
```

如果出现 `MATCH：文件完全匹配`，说明这是本工具支持的原始文件。显示 `ALREADY PATCHED` 则已经完成补丁，无需继续。出现 `UNSUPPORTED` **不要继续执行 Apply**，应核对版本和文件来源。

## 3. 应用补丁

确认 PCL 已彻底退出，并确保处理的是测试副本。在**同一个终端和文件夹**执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File ".\Patch.ps1" -Mode Apply
```

在弹出的选择窗口中，选择刚才通过预览检查的**同一个 EXE**。

看到 `PATCH APPLIED` 后，脚本会将已修复 EXE 写回原位置，并在原位置生成名为 `Plain Craft Launcher 2.exe.pcl299-original.bak` 的原版备份。

如果 EXE 正被使用、没有写入权限、已有同名备份或输出哈希不符，脚本会报错并拒绝继续。**不要删除自动备份。**

## 4. 验证功能

1. 正常双击打过补丁的 `Plain Craft Launcher 2.exe`。
2. 进入“下载”，确认 Minecraft 版本列表能加载，并在**独立的测试游戏目录**尝试安装一个版本。
3. 进入“下载 → 整合包”，打开项目版本列表，确认能选择版本并点击安装。
4. 分别选择合适的 Modrinth/CurseForge 整合包进行测试；等待“安装成功”提示，并尝试启动。
5. 有条件时另测本地 `.mrpack` 和 `.zip` 的导入安装。**这些格式并非都经过当前提交者的端到端测试。**

已进行过的实际运行测试证明本补丁针对的具体构建可恢复主要功能，但无法保证所有联网环境、整合包版本、镜像源、操作系统与游戏兼容性。

## 5. 还原原版

需要撤销补丁时，先关闭 PCL，再在同一个文件夹打开终端，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File ".\Patch.ps1" -Mode Restore
```

在弹出的文件选择窗口中，选择已打补丁的 EXE。**只有工具产生的原版备份仍存在、原版和补丁的哈希都匹配时，才会允许还原。**

还原并不会删除游戏存档和下载过的 Minecraft 文件。此前已经由别的补丁脚本修改过、但没有本工具配套备份的 EXE，不能依靠本工具自动还原。

## 6. 常见问题

**Q：我需要手动填文件夹路径吗？**
不需要。所有示例命令都是相对当前解压文件夹执行，脚本会弹出文件选择窗口。也可选用高级参数 `-TargetPath` 自行指定完整 EXE 路径，但教程不要求这样做。

**Q：可以将一版补丁用于另一版 PCL 吗？**
不能。只有精确哈希匹配才会执行。请下载与自身 EXE 对应的包。

**Q：需要每次打开 PCL 都执行补丁吗？**
不需要。补丁永久保存在已修改的 EXE 内；覆盖或升级 EXE 才可能使它消失。

**Q：Windows Defender 或安全软件提示风险怎么办？**
不要盲目关闭安全防护。补丁会更改 EXE，因此文件签名可能不再有效，也可能触发保护。确认来源、校验哈希并自行评估后再决定是否使用。

**Q：如何判断是否真的支持我的文件？**
执行 `Preview`；唯一可靠的适用性依据是完整 SHA-256，而不是外观上写着相同版本号。
